# 0003 — Standard JAMB CBT engine for both modes; drop the guide's per-question speed-drill

One shared assessment engine serves both Practice Drills and Exams: one question per screen, Prev/Next, a question-navigator grid, mark-for-review, a review/summary screen, and a **single full-duration timer** (not a per-question countdown). This deliberately overrides the developer guide's headline per-question "speed drill / auto-advance" feature, because the JAMB CBT format is what Nigerian secondary students already know cold; the "speed" comes from a tight overall time budget instead.

## Considered options
- **Standard JAMB CBT, one full-duration timer (chosen).** Familiar, reuses one engine for both modes; the only practice/exam difference is offline+local-marking vs online+server-grading.
- **Per-question rapid-fire with auto-advance.** Matches the guide's letter, but not how the real CBT/JAMB exam actually feels to a student.
